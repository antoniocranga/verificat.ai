# Dashboard Setup

Since automated Grafana provisioning via directories is not set up in this stack (the `grafana-data` volume is only mapped to `/var/lib/grafana`), you must import the dashboard model manually through the Grafana UI.

## Import Instructions

1. Open your Grafana instance in the browser.
2. Log in with your admin credentials.
3. In the left sidebar, navigate to **Dashboards > Import**.
4. You will see an option to "Import via panel json".
5. Copy the entire contents of `dashboard.json` (located in this directory) and paste it into the JSON text area.
6. Click **Load**.
7. In the next screen, you can select the folder and verify the UID (`verificat-api-monitor`).
8. Click **Import**.

## Environment Filtering

Once imported, you will notice an `environment` dropdown at the very top of the dashboard. This allows you to filter out metrics generated by staging or view them in isolation. It currently supports `All`, `production`, and `staging`. Ensure you are viewing the correct environment when diagnosing issues!

## Future Improvements

If you'd like to version control dashboards automatically, you can update `infrastructure/monitoring/docker-compose.yml` to mount a `./provisioning/dashboards` directory to `/etc/grafana/provisioning/dashboards` inside the Grafana container.
